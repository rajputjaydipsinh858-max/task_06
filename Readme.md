# Laundry App - Login Page UI

A clean, modern, and responsive login page interface built with HTML5 and CSS3 for a laundry and home-care service web application. It pairs a 3D washing machine illustration with a minimalist authentication form against a soft mint background.

## Features

- **Split-Screen Layout:** Displays the 3D washing machine graphic on the left and the login form on the right using CSS Flexbox.
- **Complete Login Form:** Includes Email and Password input fields with placeholders, a right-aligned **forgot password?** link, a full-width **Login** button, and a **register now** prompt.
- **Seamless Visual Blending:** Uses `mix-blend-mode: multiply` so the illustration blends smoothly into the mint page background.
- **Responsive Design:** Adapts cleanly from desktop screens down to mobile viewports (`max-width: 768px`) by stacking the illustration above the form.
